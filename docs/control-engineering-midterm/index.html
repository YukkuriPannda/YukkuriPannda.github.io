CHAPTER 01 / QUESTION 1

ブロック線図を連立方程式にする

図を無理に変形しない。まず信号の値を式で定義すれば解ける。

原問の図（PDF 1ページ目）

交差した線は途中で接続していない点に注意。各加算点の＋／−を確認する。

必要な知識：加算点・ブロック・負帰還

図の要素式にする方法
＋の入力その信号を足す
−の入力その信号を引く
ブロック G(s)出力 = G(s) × 入力
最終的な伝達関数G(s) = Y(s) / U(s)

途中信号を x=U−Y、上段ブロックの出力を p、下段ブロックの出力を q とおく。

x = U − Y
p = G₁(s) [x − q]
q = G₂(s) [x − p]
Y = p + q

下から上へ、上から下へ、それぞれ別の負帰還が入る。外側の帰還 Y と混同しないこと。

シミュレーター：G₁ と G₂ を変える

理解のため、ここだけ G₁・G₂ を定数として扱い、U = 1 の場合の信号を表示。一般の G₁(s), G₂(s) にも同じ代数式が成立する。

p+q = Y、かつ x = 1−Y。値を変えてもこの2つの関係が必ず成り立つことを確認しよう。

元問の解法

STEP 1：内部の交差帰還を解く

上段出力 p = G₁(x−q) に、下段の q=G₂(x−p) を代入する。

p = G₁x − G₁G₂(x − p)
(1 − G₁G₂)p = G₁(1 − G₂)x

同様に q = G₂(1−G₁)x/(1−G₁G₂)。

STEP 2：内部全体を1つの H(s) にまとめる
H(s) = Y/x
=(G₁ + G₂ − 2G₁G₂)/(1 − G₁G₂)

ここで −2G₁G₂ が現れるのは、2つの経路に交差帰還があるため。

STEP 3：外側の負帰還を入れて答える

x=U−Y より Y=H(U−Y)。したがって G=H/(1+H)。

G(s) = (G₁ + G₂ − 2G₁G₂) / (1 + G₁ + G₂ − 3G₁G₂)

分母 1−G₁G₂ で内部連立方程式を解ける通常の場合の式。特異なパラメータで代入の分母がゼロになる場合は個別に確認する。

問題文の微分方程式

y(0)=0, y′(0)=0

(s²+s)Y = (s+10)U

CHAPTER 04 / QUESTION 4

極・零点・安定性を見抜く

分母の根＝極、分子の根＝零点。安定判別は極の実部を確認する。

最重要のルール

極（pole）

伝達関数の分母を0にする s。連続時間のBIBO安定性は、約分後の伝達関数のすべての極の実部が負なら安定。

零点（zero）

伝達関数の分子を0にする s。右半平面に零点があっても、それだけで不安定とはならない。

分母 D(s)=0 → 特性方程式
Re[すべての極] < 0 → BIBO安定
Re[極] > 0 が存在 → 不安定

虚軸上の極（0や純虚数）が残る場合も、通常はBIBO安定ではない。極・零点の打消しがある場合は、伝達関数のBIBO安定性と内部安定性を区別する必要がある。

極・零点マップ（複素 s 平面）

× 極（赤）○ 零点（青緑）

縦線 Re(s)=0 を境に、右半平面に極があると不安定。第4問(a)は極−0.2と−0.25が近接するので、右の数値一覧でも確認する。

元問 第4問(a)

G(s) = (1−s)/(20s⁴+89s³+97s²+31s+3)
因数分解と解答を確認
20s⁴+89s³+97s²+31s+3
=(s+1)(s+3)(4s+1)(5s+1)

極は −1, −3, −1/4, −1/5、零点は +1。すべての極の実部が負なので 安定。ただし零点 +1 は右半平面にあるため非最小位相系。

因数分解の手順：定数項3の約数から有理根の候補を探し、見つけた因子で割り、残りをさらに因数分解する。最後に展開して係数が元に戻ることを検算。

元問 第4問(b)

G(s)=(s²+3s+2)/(s³+1)
因数分解・複素根・安定判別を確認
分子=(s+1)(s+2)
分母=s³+1=(s+1)(s²−s+1)
s²−s+1=0 → s=(1±j√3)/2

元の分母の根は −1, (1+j√3)/2, (1−j√3)/2、元の分子の根は −1, −2。

s=−1 は極・零点で打ち消し、約分後は G(s)=(s+2)/(s²−s+1)。残る2つの極の実部は +1/2 なので不安定。
