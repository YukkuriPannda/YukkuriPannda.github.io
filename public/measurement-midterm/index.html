UNIT 01

計測工学の基礎

測定は「数値を得ること」、計測は「数値を使って目的を達成すること」。ゲームのフレームレートを測るのが測定、結果を見て処理を改善するのが計測。

量の種類

種類意味・例
物理量物理法則で定義される量。長さ、質量、時間、電流、温度。
工業量工業上の評価のために定義。硬さ、真円度、平面度、表面粗さ。
感覚量人間の感覚に関係する量。味、におい、快適さ。

標準とセンサ

標準（standard）は比較の基準。校正（calibration）は標準と測定器の指示の関係を明らかにする操作で、調整とは別。トレーサビリティは、不確かさを伴う切れ目のない校正の連鎖を通じて測定結果を基準に結びつけられる性質。センサは対象の状態を検出し、トランスデューサは量を別の量・信号へ変換する。

国家標準 → 参照標準 → 作業標準 → 測定器 → 測定結果

正確さ・真度・精密さ

正確さは真値への近さ、真度は繰返し測定の平均の基準値への近さ、精密さは測定値同士の近さ。真度と精密さの両方が良ければ正確さも高い。

測定の分類

分類原理・例
偏位法指示の変化を読む。ばねばかり、指針式電流計。
零位法既知量を調節し差がゼロになるようにする。天秤、ホイートストンブリッジ。高精度だが平衡操作が必要。
直接測定目的量を直接比較する。定規、ノギス。授業の分類では零位法は直接測定に含まれる。
間接測定別の物理量から計算する。面積＝長さ×幅、熱電対の電圧から温度を推定。
絶対測定基本量に基づいて目的量を導く。圧力＝力÷面積。授業資料では間接測定の一種。
比較・相対測定標準との比較や差で求める。標準ブロックと比較して微小な長さの違いを測る。
アナログ測定連続量を扱う。量子化誤差はないが読取り誤差や雑音に注意。
ディジタル測定離散値にする。記録・演算しやすいが、量子化誤差がある。

精密測定の4手法

手法何をするか
置換法未知量を標準量に置き換え、同じ指示になる値を探す。器差の影響を抑える。
補償法既知量で未知量を打ち消す。残差を測る方式もある。
合致法二つの目盛・周期の一致から細かい端数を求める。ノギス。
差動法二つの信号の差を測って共通雑音を除く。差動増幅器、ひずみゲージブリッジ。

フィードバック制御

目標値 → 比較・制御 → 対象 → 出力
　　↑　　　　　　　　　　　↓
　　└──── 測定器 ────┘

測定値がずれると制御器が誤った操作を行う。誤差・遅れ・雑音が性能悪化や不安定化の要因になる。

UNIT 02

誤差・統計・有効数字

誤差は符号付き

e = x − X　／　相対誤差 = (x − X)/X　／　百分率 = 相対誤差 × 100 %

x：測定値、X：真値（現実には厳密には未知）。基準値を代用することがある。真値50.0 mm、測定値49.5 mmなら誤差 −0.5 mm、相対誤差 −0.01＝−1 %。

誤差原因対策
過失・粗大誤差入力間違い、誤操作原因確認、再測定
系統誤差ゼロ点ずれ、器差、温度の一定の影響校正・補正。単なる平均化では除去できない。
偶然誤差雑音、振動、変動独立な反復測定と平均化で平均値のばらつきを減らす。

平均値と分散

平均 x̄ = Σxᵢ / n
標本分散 v = Σ(xᵢ − x̄)² / n
不偏分散 s² = Σ(xᵢ − x̄)² / (n − 1)
標準偏差 = √分散

分散はばらつきの二乗の平均、標準偏差は元の測定量と同じ単位。母集団全体でなく有限個の標本から母分散を推定するなら不偏分散を使う。平均の標準不確かさ（独立な反復測定）は s/√n。

統計シミュレータ

有効数字

5.0 V は2桁、5.00 V は3桁。0.00250 は3桁、2.008 は4桁、7300 は表記だけでは曖昧なので 7.30 × 10³ のように書く。

演算規則例
加減最も粗い小数位にそろえる2.35 + 1.234 = 3.58
乗除最も少ない有効桁数にそろえる2.5 × 3.141 = 7.9

規則A（偶数丸め）：ちょうど中間なら残す桁が偶数になる方向に丸める。2.25→2.2、2.35→2.4。規則B：通常の四捨五入。計算途中で何度も丸めず、最後に一度だけ丸める。

誤差伝播：最大誤差の評価

A ± ΔA、B ± ΔB
和・差：Δ(A ± B) = ΔA + ΔB
積・商：Δy/|y| ≈ ΔA/|A| + ΔB/|B|
べき乗：Δy/|y| ≈ |m| Δx/|x| （y = xᵐ）

差でも誤差は足す。積・商・べき乗は微小誤差の一次近似。例：20±1 と 5±0.2 の積は100、最大相対誤差5%+4%=9%、結果100±9。

不確かさ：統計的な評価

誤差そのものと違い、不確かさは測定値に帰属する値のばらつきの程度。タイプAは反復測定等の統計的評価、タイプBは校正証明・仕様書等の別の情報による評価（補足：資料中のタイプ表記は一般的定義と異なる箇所がある）。幅±a の一様分布なら u=a/√3。

u꜀ = √Σ[(∂f/∂xᵢ)uᵢ]²　（独立な入力）
U = k u꜀　（拡張不確かさ。k=2 がよく使われる）
積・商：u꜀/|y| = √[(uA/A)²+(uB/B)²]

最大誤差は絶対値の和、不確かさは独立なら二乗和の平方根。相関がある場合は共分散も必要。

誤差伝播計算機

例題：円柱の直径20±0.2 mm、高さ50±0.5 mm。体積の最大相対誤差は？

V=πd²h/4。2×0.2/20 + 0.5/50 = 0.03 = 3 %。体積は約15708 mm³、最大誤差約471 mm³。独立な標準不確かさとして扱うなら √(0.02²+0.01²)=約2.24 %。

UNIT 03

最小二乗法

点が散らばっているとき、「全体に最もよく合う直線」を数学的に探す。各点と直線の縦方向の残差を二乗して足し、最小にする。

y = ax + b　／　残差 eᵢ = yᵢ − (axᵢ+b)
S = Σ eᵢ² → 最小

二乗する理由：正負の残差を打ち消さず、大きなずれを強く罰するため。a、bで偏微分しゼロと置く。

Σy = aΣx + nb
Σxy = aΣx² + bΣx
a = (nΣxy − ΣxΣy)/(nΣx² − (Σx)²)
b = (Σy − aΣx)/n = ȳ − ax̄

例題の解き方

点(1,2)、(2,3)、(3,5)。n=3、Σx=6、Σy=10、Σx²=14、Σxy=23。a=(69−60)/(42−36)=1.5、b=(10−9)/3=1/3。したがって y≈1.5x+0.333。

近似直線を動かしてみる

スライダーで傾き・切片を調節。赤い線は残差。最小二乗のボタンで最適解に合わせる。

他の形の最小二乗法

一定値の推定：Σ(xᵢ−c)² を最小にする c は平均値。原点を通る y=kx は k=Σxy/Σx²。多変数の線形モデル y=Xβ では正規方程式 XᵀXβ=Xᵀy。線形予測は過去の観測値の線形結合で現在値を推定する。外れ値の影響と、xがすべて同じ場合に傾きを求められないことに注意。

確認：原点を通る近似と普通の直線近似の違いは？原点を通る場合は切片をゼロに固定する。一般の場合は傾き・切片の両方を推定する。
UNIT 04

物理量・次元・国際単位系

物理量の表し方

物理量 = 数値 × 単位

5 m の5は数値、mは単位。1 m = 100 cm でも物理量は同じ。次元は量の種類を示し、単位は測る尺度。

区別内容
示量変数 extensive均一な対象を2倍にすれば2倍になる。質量、体積、電荷、エネルギー。
示強変数 intensive対象を2倍にしても通常変化しない。温度、密度、圧力、電位。
位差量 across二点間にまたがる量。電圧、圧力差、温度差。
流通量 through要素を通過する量。電流、流量、熱流率。

電気 V=RI、流体 Δp=RQ、熱 ΔT=RₜQ̇ は同様の構造。機械系では力・速度、トルク・角速度が共役の組。力と速度の across/through の割当はアナロジーの規約によるため授業表も確認。インピーダンスは抵抗等を一般化した比（電気では Z=V/I）、アドミタンスは逆数 Y=1/Z。抽象化により異なる分野を同じ数式で扱える。

次元解析

dim Q = Lᵃ Mᵇ Tᶜ Iᵈ Θᵉ Nᶠ Jᵍ
量式次元

加減算できるのは同じ次元の量。式の両辺の次元は一致しなければならない。摩擦係数、屈折率、レイノルズ数は無次元量（単位1）。

UNIT 05

度量衡・時間・長さの標準

第2回・第3回の課題名および試験指定語から補った一般的な解説。度量衡の独立した講義資料・教科書本文は未取得。

度量衡とは

度＝長さ、量＝容積、衡＝重さ（質量）を測る体系。社会で共通の尺度を用いるために標準を決め、測定結果を比較できるようにする。

時間と秒

かつて地球の自転・公転を基準にした時間が使われていた。現代の1秒はセシウム133原子の超微細遷移の周波数を9,192,631,770 Hzと固定して定義する。TAIは原子時計に基づく時刻系、UT1は地球自転に基づく時刻系、UTCは国際的な協定世界時。

うるう秒（leap second）は地球自転の不規則さと原子時計による時刻との差を調整する仕組み。うるう年とは別物。

メートルの定義の変遷

1791 地球の子午線の長さを基準

1889 国際メートル原器

1960 クリプトン86の光の波長

1983 真空中の光速を固定して定義

c = 299,792,458 m/s（正確な定義値）
1 m = 光が真空中を 1/299,792,458 s に進む距離

人工物は劣化や複製誤差があるため、普遍的な物理現象を基準にすると再現性を確保しやすい。質量も国際キログラム原器からプランク定数に基づく定義へ移行した。

UNIT 06

長さ計測技術

配布資料のテキスト抽出に文字化け・図の欠落があったため、読み取れた見出しと一般的な原理から再構成した章。図や教科書固有の記述は未照合。

接触式と非接触式

方式代表例・特徴
実体標準定規、標準尺、ブロックゲージ。実際の長さを基準とする。線度器は目盛線間、端度器は端面間の距離で長さを表す。
機械的接触ノギス、マイクロメータ。安価で扱いやすいが接触力や温度、姿勢に注意。
光学式干渉計、レーザー距離計。非接触で精密または長距離の測定。
電気式・磁気式LVDT、渦電流センサ、エンコーダ。変位を電気信号へ変換。

ノギス：合致法

主尺1目盛を u、副尺 n 目盛を主尺 n−1 目盛に合わせると、副尺1目盛 v=(n−1)u/n。最小読取値 u−v=u/n。u=1 mmなら10分割で0.1 mm、20分割で0.05 mm、50分割で0.02 mm。

測定値 = 副尺ゼロの左側の主尺値 + 一致した副尺番号 × 最小読取値

ノギス読取り練習（0.05 mm）

マイクロメータ：ねじの回転を直線変位に

ねじピッチ p、シンブルの分割数 N なら最小読取値 p/N。p=0.5 mm、50分割なら0.01 mm。スリーブの整数・0.5 mm目盛を読み、シンブルの値を加える。副尺付きでは0.001 mm読取も可能。ラチェットは測定力を一定に近づける。

例題：スリーブ7.5 mm、シンブル23、最小読取0.01 mm。7.5 + 23×0.01 = 7.73 mm。

アッベの原理

測定対象の測定軸と標準尺の軸を同一直線上に配置すると角度誤差の影響を小さくできる。軸のずれ h があると微小角 θ に対して誤差 e≈hθ。一般的な外側マイクロメータは軸を合わせやすく、ノギスは測定対象が目盛軸から離れやすい。

ブロックゲージ

端面間の距離が正確に定まった端度器。平滑な面同士を密着（リンギング）させて積み重ね、必要な標準長を作る。校正・比較測定に使用。温度（標準参照温度20 ℃）や汚れ、密着状態が精度に影響する。

光学・電気による測定

原理説明
レーザー干渉計基準光と測定光の位相差・干渉縞を数えて変位を求める。往復光路なら ΔL=Nλ/2。高精度だが空気の屈折率などに注意。
ToF光を照射し往復時間 Δt を計測して距離 L=cΔt/2 を求める（真空近似）。LiDAR等。
エンコーダ移動量をパルスやコードに変換。インクリメンタル型は相対移動量、アブソリュート型は絶対位置。
LVDT（差動変圧器）交流励磁した一次コイルと二つの二次コイル。可動鉄心の位置で二次電圧差が変わり、中央で差がほぼゼロになる。
ひずみゲージ物体の伸縮で抵抗が変わる。ひずみ ε=ΔL/L、ゲージ率 GF=(ΔR/R)/ε。ブリッジ回路で微小変化を測定。
GPS衛星からの信号の伝播時間を使い疑似距離を求める。通常4衛星以上から位置3成分と受信機時計のずれを推定。

波長 λ=c/f。物体の熱膨張 ΔL≈αLΔT。例：長さ100 mm、線膨張係数12×10⁻⁶/K、温度差10 Kなら伸び0.012 mm。

例題：レーザーの往復時間が20 ns。距離は？c×20×10⁻⁹/2≈3.0 m。往復なので必ず2で割る。
